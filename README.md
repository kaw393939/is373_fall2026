# IS373 Fall 2026

A Next.js app with TypeScript and Docker. Docker supplies the app’s Node.js environment, so you do not need to install Node.js separately.

## Start here

1. Set up Docker: [Mac](docs/setup-mac.md) or [Windows with WSL 2](docs/setup-windows.md).
2. Follow [Run the app](docs/run-the-app.md) to download the project and start it.

## Learn and reference

- [Docker and containerization](docs/docker-basics.md) — a short introduction for beginners.
- [Development reference](docs/development.md) — project files, checks, production mode, and optional Node.js commands.

Already set up? Go straight to [Run the app](docs/run-the-app.md).
